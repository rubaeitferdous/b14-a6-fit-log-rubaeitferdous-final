# FitLog

FitLog is a focused workout library and daily training log. Browse strength and conditioning movements, open a detailed exercise guide, then build a five-lift plan for today or save workouts for later.

## Features

- Browse a responsive library of workouts loaded from the FitLog API.
- View workout details, including equipment, difficulty, sets, reps, calories, and instructions.
- Add up to five exercises to today’s plan and mark completed lifts.
- Save workouts for later, with plan and saved counts visible in the navigation.
- Sort plan and saved lists by duration, calories, or rating.
- Persist your plan, saved list, and completion status in local storage.
- Responsive layouts for mobile, tablet, and desktop.

## Technology

- Next.js App Router
- React
- Tailwind CSS
- FitLog Workers API

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
